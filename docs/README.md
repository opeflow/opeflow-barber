# Guias do Opeflow Barber

Este índice separa as orientações por público:

- [Guia do proprietário](./guia-proprietario.md): primeiros passos, configurações e rotina de gestão.
- [Guia do barbeiro e da equipe](./guia-equipe.md): uso operacional seguro e limites dos acessos individuais nesta versão.
- [Guia do cliente](./guia-cliente.md): como ser atendido hoje e o que estará disponível quando o portal do cliente for lançado.
- [Acessos de desenvolvimento](./acessos-desenvolvimento.md): como criar dados de demonstração e usar os logins padrão por perfil.

## Estado desta versão

O painel interno oferece cadastro inicial da barbearia, identidade visual, link público de agendamento, convites individuais para a equipe, serviços, profissionais, horários de trabalho, clientes, agenda, fila presencial e registro de pagamentos. Logins de desenvolvimento para proprietário, barbeiro, cliente e administrador global estão disponíveis via seed; a área de cliente é somente leitura e o painel administrativo é apenas uma base de autenticação. Cadastro de clientes, recuperação de senha, cancelamento/reagendamento pelo cliente e ferramentas globais administrativas seguem pendentes.
