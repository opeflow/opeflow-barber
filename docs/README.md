# Guias do Opeflow Barber

Este índice separa as orientações por público:

- [Guia do proprietário](./guia-proprietario.md): primeiros passos, configurações e rotina de gestão.
- [Guia do barbeiro e da equipe](./guia-equipe.md): uso operacional seguro e limites dos acessos individuais nesta versão.
- [Guia do cliente](./guia-cliente.md): como ser atendido hoje e o que estará disponível quando o portal do cliente for lançado.

## Estado desta versão

O painel interno oferece cadastro inicial da barbearia, identidade visual, link público de agendamento, convites individuais para a equipe, serviços, profissionais, horários de trabalho, clientes, agenda, fila presencial e registro de pagamentos. O agendamento público aceita novas reservas sem conta; consulta/cancelamento pelo cliente, recuperação de senha e matriz completa de permissões ainda não foram implementados. Os guias identificam esses limites.
